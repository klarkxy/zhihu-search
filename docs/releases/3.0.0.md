# zhihu-search v3.0.0

本版本默认保护免费额度，并修正知乎开放平台的新额度分组。默认调用行为改变，因此从 2.1.2 升级为 3.0.0；工具名、业务路径和响应主体保持原样。

## 破坏性行为变化与迁移

- CLI、MCP、OpenAPI、Python 客户端的业务 HTTP 请求统一先通过本地保护。默认免费模式每次即时查询官方免费额度，预查失败、额度缺失/无效、容量不足或没有可靠映射时不发送业务请求。
- 默认北京时间每日上限为 **100 次业务发送预留/尝试**。已持久化预留后失败、取消或结果未知的请求也占上限；失败的额度预查不占上限。额度查询自身不递归预查、不计入上限，达到上限后仍可查询。
- 已有 Access Secret、环境变量、OAuth 配置及凭据文件继续沿用，无需生成新凭据。2.x 曾自动在免费额度耗尽后继续调用的使用者，需显式启用付费续用；不能假定升级后仍按旧行为发送。
- 免费模式允许有可靠额度分组的未列价能力，包括 fast/thinking 直答、问题推荐和 PDF/PPT 任务。只有显式付费模式才保守拒绝未确认计费的能力，不估算或套用其他服务价格。
- 通用资源文件上传 `/resources/v1/files` 尚无可靠额度映射，暂时失败关闭；知识库上传的 `knowledge` 映射已确认。PDF 上传流程的使用者请暂时保留 2.x 或等待官方明确合同，不将本版本的上传拒绝误认为授权绕过需求。

## 配置方式

默认无需配置。每日上限可设为 1–100000；CLI 全局参数放在子命令前：

```bash
zhihu-search --daily-call-limit 50 search "普通资料"
zhihu-search --allow-paid --daily-call-limit 50 search "普通资料"
```

`--allow-paid` 是本次进程的显式付费许可，仍受每日上限约束，不会充值或开通平台权限。CLI/MCP/OpenAPI 的启动环境也支持 `ZHIHU_ALLOW_PAID=true` 与 `ZHIHU_DAILY_CALL_LIMIT=50`；默认分别为 false、100。业务工具参数不接收付费开关或密钥。

## 额度兼容与本地状态

- 官方问题发现额度 ID 改为 `question_discovery`，问题推荐和回答摘要共用该组。旧输入 `question_answers` 继续接受，并在请求前映射和去重；`question_answers` 工具名及业务 URL 不变。
- 本地保护记录位于 `~/.config/zhihu-search/call-policy/`，只保存计数和预留，不保存凭据、请求内容或钱包余额。旧 `quota.json` 不读取、不删除。本地计数不是官方额度或账单。
- `ZHIHU_SEARCH_HOME` 可覆盖根目录，`ZHIHU_CALL_POLICY_DIR` 可指定共同保护目录。共用目录的进程/账号共用本地上限；Python 与本地 dsh-zhihu 实现的目录互斥和 JSON 格式兼容。自定义目录应使用同一绝对路径。
- 锁覆盖额度预查与整个请求，先持久化预留再发送。每次仍查询官方额度，同时用不自动补回的本地容量上限防止复用滞后的官方值。该上限不作为官方余额展示；北京时间跨日重置每日上限和该容量上限，未知结果预留仍保留。
- 不自动重试。网络结果未知时先核对官方记录；崩溃遗留锁不自动抢占。确认相关客户端均无在途请求并核对未知结果后，才可手动移除 `request.lock`；损坏记录失败关闭，不静默清零。

## 竞争窗口与验收边界

本地保护**不能承诺绝对零费用**：同账号其他客户端可能在预查后竞争免费额度，平台额度更新也可能滞后。API 计费不会扩大内容访问、转载或传播授权范围。本版本没有新增充值、权益兑换、钱包查询、SortBy 或付费正文接口。

- 271 项完整 Python 测试通过，涵盖 CLI/MCP/OpenAPI 请求层、免费/付费差异、上限、预查失败、并发、取消及额度滞后。
- 保护模块与 HTTP 客户端 Pyright 零诊断。全源检查与发布前 HEAD 对比均为 19 处既有类型诊断，零新增；本次未扩展为类型系统重构。
- Python/TypeScript 四进程互操作 mock 验证：20 次竞争请求仅放行模拟免费容量允许的 3 次；显式付费 mock 仅放行本地上限允许的 5 次。付费模式未做真实扣费测试。
- 使用现有认证通路完成 2 次真实热榜请求和 6 次额度查询。Python 返回的热榜剩余额度为 100→100，故增加保守预留上限；最后一次额度查询遇到限流，立即停止且未重试。不能据本地计数推断实际扣费。
- DSH 宿主 UI 未做真实图形验收：当前浏览器控制工具初始化受限。dsh-plugins 的改动仅保留在本地，不属于本次提交或发行。
