# zhihu-search v3.1.0

本版本加入知乎同步发布：把已有文章、提问或想法适配成知乎格式，本地预览，并在明确确认后发布。搜索、直答、热榜和原有 MCP 档位保持不变，`compact` 默认仍然只有 `search`、`ask`、`trending`、`other`。

## 新增能力

- CLI：`sync-save`、`sync-list`、`sync-get`、`sync-prepare`、`sync-preview`、`sync-publish`、`sync-upload-image`。
- Python：`zhihu_search.sync` 与 `zhihu_search.openapi_credentials`。
- MCP 档位 `sync`：上述能力对应 7 个工具。`full` 仍是原来的 23 个工具，`other` 不会展开同步工具。OpenWebUI 不提供发布。
- 发布凭证与搜索 Access Secret 分开。环境变量 `ZHIHU_OPENAPI_APP_KEY` / `ZHIHU_OPENAPI_APP_SECRET` 优先，其次是 `~/.config/zhihu-search/openapi-credentials.json`，再其次是官方同步助手的 `~/.zhihu/openapi-credentials.json`。来源冲突时拒绝猜测。
- `--save-openapi` 接受整段授权说明，并从中读取 `ZHIHU_OPENAPI_APP_KEY:"…"` 与 `ZHIHU_OPENAPI_APP_SECRET:"…"`。`--check-openapi` 只报告来源和 App Key。`--clear-openapi` 只删除本包保存的文件。

## 发布是确认后的动作

校验和预览不会发布。`sync-publish` 必须带 `--confirm` 和当次 `preview_token`；MCP 的 `sync_publish` 默认 `confirmed=false`。没有这组确认时不会请求知乎。标题或正文超限只报错，不截断。视频会直接拒绝。发布结果不确定时草稿被锁定，避免重复发送。

发布请求只发往 `https://openapi.zhihu.com`，使用 HMAC-SHA256 签名。App Secret 和签名不会进入工具参数、错误文本或请求文件。图片只支持 JPEG、PNG、GIF、WebP、BMP。

这组接口不走搜索 Access Secret 的免费额度预检。本机另有北京时间每天最多 50 次发布尝试的上限，可用 `ZHIHU_SYNC_DAILY_PUBLISH_LIMIT` 调到 1–50。计数损坏时失败关闭。

## 上游说明

格式、预览确认和 `POST /openapi/publish` 的规则来自知乎官方「知乎同步助手」（仓库 [Zhihu/ZhihuSync](https://github.com/Zhihu/ZhihuSync)，MIT，author zhihu）。本仓库是独立实现，没有逐字收录上游 Skill 正文。申请入口以 <https://www.zhihu.com/playground/zhihu-sync> 为准。

## 兼容

- 已有 Access Secret、OAuth 配置和调用保护行为不变。
- 工具名、搜索路径和 `compact` 默认目录不变。
- 从 3.0.0 升级不需要重新保存搜索凭证。发布凭证需要单独配置。
