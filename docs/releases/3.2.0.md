# zhihu-search v3.2.0

本版本加入三条可选研究流程：深度研究、知乎观察、近况速览。它们不是新的知乎 HTTP 端点，而是在已有搜索、全网搜索、知识库检索和问题回答摘要上编排证据，再由宿主写结构、由本地渲染器校验。搜索、直答、热榜、同步发布和调用保护保持不变。

从 3.1.0 升到 3.2.0，是因为这是一组新的独立入口，不是对已有 `search` / `ask` 的修补。旧命令、JSON 契约和默认 `compact` 档位没有改行为，所以不是主版本。

## 新增能力

- CLI：`research deep|observe|recent` 返回证据包；`research-render` 校验宿主写出的 `zhihu-search.report.v1`，生成本地 `report.md`、`report.json` 和单文件 `report.html`。
- MCP：`research`、`research_render`。它们不在 `compact` 里，`full` 和 `other(enable)` 可见。
- OpenAPI：`POST /research`、`POST /research/render`。渲染不访问知乎。
- 近况窗口使用全网 `SearchDB=realtime` 和官方 Filter 写法 `host=="example.com" AND publish_time>=<unix>`。知乎搜索没有日期参数。

证据包的 `html` 为空。确认的事件日期必须是证据窗口内的真实日历日，并且出现在摘录的事件上下文里。假设不能进入确认时间线。报告 `publishable` 为 false，不会自动发布。

## 兼容

- 已有 Access Secret、发布凭证、OAuth 和调用保护不变。免费额度预检、北京时间每日上限、未知映射拒绝、失败不重试和显式付费开关仍在。模型参数不能打开付费或提高每日上限。
- `search`、`ask` 和同步发布的参数与确认规则不变。
- 从 3.1.0 升级不需要重新保存凭证。
